# قائمة أمان قبل النشر العام

- استخدم HTTPS دائماً، وكلمة مرور إدارة قوية وفريدة و`SESSION_SECRET` عشوائي طويل.
- لا تحفظ أسرار المزود في APK أو HTML أو مستودع GitHub؛ استخدم Secrets/Environment Variables في الخادم.
- احتفظ بقاعدة SQLite في قرص دائم، وفعّل نسخاً احتياطية واختبر الاستعادة.
- راجع سجلات الدخول الفاشلة وفعّل تحديد المعدل على مستوى reverse proxy أيضاً.
- راجع سياسة الجلسات وCSRF وCSP مع إعداد الاستضافة الفعلي قبل إطلاق خدمة عامة متعددة المستخدمين.
- أضف حسابات منفصلة وصلاحيات مناسبة قبل فتح لوحة الإدارة لأكثر من مسؤول.
- لا تحتفظ بعنوان محفظة أو بيانات شخصية أكثر مما تتطلبه عملية السحب؛ لا تسجل مفاتيح خاصة مطلقاً.
- لا تنفذ دفعات تلقائية ولا تعرض أرصدة على أنها قابلة للسحب إلا بعد تأكيدها من المصدر الرسمي.
- احصل على موافقة المستخدم قبل مشاركة الإنترنت، ووضح أن حركة المرور قد تمر عبر عنوان IP المنزلي وشروط الاستخدام.
- تحقق من شروط مزود الإنترنت المحلي والقوانين والضرائب ومتطلبات الخصوصية قبل الإطلاق.

هذه قائمة بدء وليست تدقيقاً أمنياً مستقلاً أو شهادة امتثال.
