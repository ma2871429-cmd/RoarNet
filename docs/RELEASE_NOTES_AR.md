# ملاحظات النسخة 0.3.0

- توحيد مسار خادم Node.js مع `npm start`.
- إضافة تحديد أولي لمحاولات تسجيل الدخول الفاشلة.
- إضافة ترويسات أمان أساسية للوحة.
- احتساب طلبات السحب المعلقة ضمن الرصيد المتاح لمنع تكرار طلب نفس الرصيد.
- إضافة وثائق الشراكة والنشر والأمان والخصوصية.
- إضافة اختبارات API أساسية.
- إبقاء مشاركة الترافيك والسحب الآلي معطّلين افتراضياً.

المتبقي قبل الإطلاق التجاري: موافقة المزود، وثائق API/SDK الرسمية، الاستضافة الفعلية، إعداد HTTPS والأسرار، اختبار تكامل حي، وربط دفع رسمي.
