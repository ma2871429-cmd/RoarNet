# مسودة إشعار الخصوصية — تحتاج مراجعة قبل النشر

RoarNet مشروع لمشاركة سعة الإنترنت بموافقة المستخدم عبر مزود شريك. عند تفعيل الخدمة قد يعالج التطبيق أو الخادم بيانات الحساب، حالة الاتصال، حجم الترافيك، معرّفات الأجهزة لدى المزود، سجلات الأخطاء، وطلبات السحب. تستخدم بيانات الأرباح فقط لمطابقة تقارير المزود وإدارة الطلبات.

لا تفعّل مشاركة الاتصال قبل عرض اسم المزود، نوع البيانات، غرض الاستخدام، طريقة الإيقاف، وسياسة الاحتفاظ والمشاركة مع الأطراف الأخرى والحصول على موافقة صريحة. لا ترسل كلمات المرور أو المفاتيح الخاصة إلى الخادم. يحق للمستخدم طلب حذف بياناته وفق المتطلبات القانونية والعقدية المعمول بها.

هذه مسودة عامة وليست سياسة نهائية؛ يجب تخصيصها بحسب SDK الحقيقي، الاستضافة، البلدان التي يخدمها التطبيق، والالتزامات القانونية قبل نشر التطبيق.
