# RoarNet — حزمة المصدر الجاهزة للاختبار

حزمة مشروع تشمل تطبيق Android (WebView)، لوحة عربية، خادم Node.js، قاعدة SQLite، سجل حسابات منفصل للتجريبي والمؤكد، ملف إعداد، اختبارات، ومستندات تجهيز الشراكة.

## الحالة بوضوح
- الواجهة والخادم وقاعدة البيانات موجودة ضمن الحزمة.
- البناء التلقائي لنسخة Android التجريبية متوفر عبر GitHub Actions.
- مشاركة الإنترنت الفعلية **غير مفعلة**: تحتاج موافقة مزود رسمي وSDK/API موثق ومسموح استخدامه داخل تطبيق شريك.
- الأرباح الحقيقية لا تظهر إلا بعد ربط بيانات موثقة من المزوّد بمراجع فريدة. لا توجد أرباح مضمونة.
- السحب USDT الآلي **غير مفعّل**. الطلبات تسجل للمراجعة اليدوية فقط؛ لا ترسل معاملة بلوكشين.
- موصل المزود في `src/server.js` قالب تكامل، ومسار API فيه افتراضي ويجب استبداله حسب وثائق المزود الرسمية. اترك `PROVIDER_ENABLED=false` حتى تتوفر الوثائق والموافقة.

## تشغيل الخادم محلياً (Node.js 22.13+)
1. انسخ `.env.example` إلى `.env`.
2. أنشئ قيمة عشوائية طويلة لـ `SESSION_SECRET` وكلمة مرور إدارة فريدة بطول 16 حرفاً أو أكثر.
3. ثبّت Node.js 22.13 أو أحدث، ثم من مجلد المشروع شغّل `npm run check` ثم `npm test` ثم `npm start`.
4. افتح `http://localhost:3000`. لا تعرض الخادم مباشرة للإنترنت دون HTTPS واستضافة دائمة ونسخ احتياطي.

> الخادم يستخدم `node:sqlite` المتوفر في إصدارات Node الحديثة؛ تأكد أن منصة الاستضافة تدعم Node.js 22.13+ وSQLite وتخزيناً دائماً. إذا كانت المنصة تنام أو تحذف الملفات، ستضيع قاعدة البيانات.

## إنشاء APK من الموبايل
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد (المجلد نفسه، مو ملف ZIP).
2. افتح **Actions** وشغّل **Build RoarNet APK**.
3. بعد نجاح المهمة نزّل Artifact باسم `RoarNet-debug-APK`، فك الضغط وثبّت `app-debug.apk`.
4. النسخة الافتراضية تعرض شاشة تعريفية فقط. بعد نشر الخادم على HTTPS، ضع رابطك في `SERVER_URL` بملف `app/src/main/java/com/roarnet/app/MainActivity.java`، ارفع التغيير وأعد البناء.

## إعداد الشراكة
راجع `docs/PARTNER_ONBOARDING_AR.md`. لا تضع أي API key أو token أو كلمة مرور في Android أو داخل GitHub. خزّن أسرار المزود في متغيرات بيئة الخادم فقط. لا تفعّل الموصل قبل تأكيد قبول العراق، شروط التطبيق الشريك، طريقة احتساب الأرباح، الحد الأدنى للسحب، العملة والشبكة والرسوم.

## الملفات المهمة
- `src/server.js`: الخادم وواجهات API.
- `public/index.html`: لوحة الإدارة.
- `app/`: مشروع Android.
- `tests/`: اختبارات smoke للخادم.
- `docs/`: متطلبات النشر والشراكة والخصوصية والأمان.
